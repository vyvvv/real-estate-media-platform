# Real Estate Media Platform Frontend

本目录包含 Real Estate Media Platform 的 React 前端。

完整的项目目标、当前进度、本地环境要求和开发路线请阅读仓库根目录的 [README](../README.md)。

## 启动

```powershell
npm.cmd install
npm.cmd run dev
```

默认开发地址：<http://localhost:5173>

前端当前默认请求运行在 <http://localhost:5166> 的后端 API。

## 检查

```powershell
npm.cmd run build
npm.cmd run lint
```
